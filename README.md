# Real Sparkle?

A 2D pixel-style rooftop endless runner built with Python and Pygame.

Current Features:
- Infinite procedural platform generation
- Double jump
- Fast-fall mechanics
- Sliding movement system
- Multi-layer rooftop environment

Work in progress.
